# 口播自动扩写修订

把未通过的口播扩写为完整、自然的任意主题视频叙事。活动需求只是种子，应根据实际主题补充问题背景、关键概念、步骤方法、场景经验、行动建议和 CTA，不能强行加入商业获客或固定行业内容。

- 优先写到 320–420 字、12–18 句。
- 最终 80–500 字、至少 3 句即可继续。
- 不得编造数字、经历、案例、价格或效果承诺。
- 每个完整句子单独成为一条字幕，不设置字幕字数上限，不截断，不把两个半句拼成一条。
- 只有 `。！？!?` 表示完整句子结束。
- 只输出严格合法 JSON。
