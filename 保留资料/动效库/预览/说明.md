# 能力卡预览

一个纯本地页面，用来**肉眼过一遍全部 112 张能力卡**，把不要的标掉，再把清单交回给我。

## 打开

双击 `index.html`，或者：

```bash
open "保留资料/动效库/预览/index.html"
```

不需要服务器，不需要联网。

## 怎么用

| 操作 | 效果 |
|---|---|
| 鼠标移到预览框 / 点一下 | 单独播这张卡 |
| 顶部「全部播一遍」 | 按顺序每隔 1.2 秒播一张（只播当前筛选结果） |
| 顶部搜索框 | 按编号或名字过滤，如 `K03`、`擦除` |
| 顶部族标签 | 只看某一族（镜头/字形/材质…） |
| 卡片下方「标记删除」 | 标红并划线；再点一次取消 |
| 底部「复制删除清单」 | 复制成 `X12 X14 …`，直接贴回对话 |
| 底部「复制保留清单」 | 反过来复制没被标的 |

标记存在浏览器 localStorage 里，关掉页面再打开还在。「清空标记」一键全清。

## 注意

- 预览是**缩略版**：只演动作本身，不做真实排版，字号/配色按样张统一。
- 预览会把超过 2.2 秒的时长压到 2.2 秒，并循环播放，底部有一条进度条——**动作幅度小的卡（比如 C01 只推 6%）靠进度条才看得出在动**。
- 材质（M 系列）在缩略图里偏淡，放大看更明显。
- 背景（B 系列）用 canvas 实时画，每个 6 秒循环一次。
- 预览里的数据是占位，不代表真实业务。

## 改完卡之后

`cards.js` 是生成的，不要手改：

```bash
python3 保留资料/动效库/build_presets.py --demo 保留资料/动效库/预览
```

删卡：从 `presets.json` 里删掉那条，再跑一次 `sync_expander.py` 和上面这条命令。
