# 组件卡（U 系列）

样式在 `assets/vendor/components.css`，本地渲染前自动注入。**只写下面这些结构，不自己加样式、不加图形。**

变量只用 `--ui-*`；同一支片子只改颜色与圆角，不改结构。

## U01 信息卡片

```html
<div class="ui-card" data-anim="card-1">
  <h3>标题最多两行</h3>
  <p>一句解释，不超过 24 字。</p>
</div>
```

## U02 步骤条

```html
<div class="ui-steps" data-anim="steps">
  <div class="ui-step is-done"><b>搜客户</b><span>10 分钟</span></div>
  <div class="ui-step"><b>发消息</b><span>自动</span></div>
  <div class="ui-step"><b>跟进度</b><span>提醒</span></div>
</div>
```

进度靠加 `.is-done` 或用 `timeline.to(el, {width:'100%'})` 动 `::after` 做不到，改为给 `.ui-step` 加一个内联 `<i class="bar">` 时自行补样式——**默认只用 `.is-done` 切换**。

## 规则

1. 一屏最多 **2 个** U 编号；相邻两屏不能重复同一组合。
2. 组件里的数字用 T06 递增，不要自己写 `textContent` 循环。
3. 组件受光（P02）只挂在 `.ui-card` 上，一行里不要挂两个。
4. 不要给组件加 `<svg>`、`<canvas>`、图标字体或 emoji 代替图标。
