# 动效能力卡（给写 GSAP 的节点看）

这一屏能用哪些动作、参数范围多少、什么时候别用。**按编号选，不要自己发明动作参数。**

> 想肉眼过一遍全部卡片：打开 `保留资料/动效库/预览/index.html`（本地页面，悬停即播，可标记删除并复制清单）。

## 三条硬规则

1. **只选下面表里的编号**，参数只在这个编号给的范围内调；表里没有的动作，不要写。
2. **每屏条数不设上限**：一屏可以有 6–12 条动作，按「1 个镜头(C) + 1 个环境(D) + 1 个主运动(K/U) + 2–4 个次级(G/S) + 1 组离场(X)」组织，同族可以叠加；相邻两屏不能同镜头、不能同主运动。
3. 禁止 `requestAnimationFrame`、`performance.now`、`Math.random`、`yoyo`/`repeat` 循环；随机一律用 `kit.seeded(种子)`。

## 怎么用

**模型只输出判断，不写代码**（编号的展开代码见 `presets.json`，由 `build_presets.py` 派生 Dify 模板与样张）：`{"preset":"T01","target":"title","trigger":"word:答案","fallback":1.2,"params":{"stagger":0.06}}`。
本地 `H02SX` 按编号展开成 GSAP 并塞进这一屏。所以：

- 不用记写法，只要选对编号、填对 `target`。
- 代码永远一致，不会因为模型自由发挥而退化。
- 展开模板在 `保留资料/工作流代码节点/expand_motion_plan.py`。

## 镜头（C 系列，2026-11 新增）

整屏为单位、持续 3–5 秒的运动。**和元素入场是两层**：入场 0.5 秒，镜头整屏。

| 编号 | 名字 | 参数 | 什么时候用 | 别用在哪 |

| C01 | 缓推 | scale 1→1.06（上限 1.2）· 整屏时长 | 几乎每屏都能用；照片、图块、满屏图层 | 纯色屏；推超过 20% 会露边 |
| C02 | 缓拉 | scale 1.08→1 | 开场收束、结尾释放 | 满屏照片拉太小会露底色 |
| C03 | 横移 | xPercent −3→3（上限 ±6%） | 左右取景，字固定 | 幅度超过 6% 露边 |

## 通用底层能力（任何卡、任何手写场景都能直接调）

`motion-kit.js` 里这 5 个函数不属于某一族，所有卡都能用：

| 函数 | 作用 | 典型用法 |
|---|---|---|
| `kit.fitText({text,withinWidth,fontFamily,fontWeight})` | 反算填满宽度的字号 | 标题自动撑满栏宽 |
| `kit.fitScale(el, ratio)` | 量出要放大几倍才填满父级 | K20 撑满一行 |
| `kit.noise2(x,y,seed)` | 确定性 value noise | 有机漂移、手抖、颗粒 |
| `kit.pathAt(el,p)` | 按进度画 SVG 路径 | 折线、连线、手绘线 |
| `kit.drawPath(timeline,sel,at,dur)` | 时间线驱动的路径绘制 | U14 折线、节点连线 |

## 派生与校验

```bash
python3 保留资料/动效库/build_presets.py --demo <目录>   # 生成样张用的 cards.js
python3 保留资料/动效库/sync_expander.py                 # 把 ready 卡同步进 Dify 的 H02SX
python3 保留资料/动效库/sync_expander.py --check         # 只在 CI/交付前检查是否同步
```

**加卡的完整流程**（三步，缺一步就等于没加）：

1. 改 `presets.json`（唯一源）
2. 跑 `sync_expander.py`——展开器里的 `TPL` / `DEFAULTS` 是生成的，不再手抄
3. 跑 `build_presets.py --demo <目录>` 出样张验证
