# 成品目录

`成品/` 只放跑出来的东西，分四类。**"现在该做什么"看 `项目状态.md`**，这里只说"东西归哪儿、留多久"。

```text
成品/
├── <项目名>/            正式项目：日期或名字命名，一个项目一个目录
├── 试验/<项目名>/        没上线 / -check / -rebuild / 结构测试 / 图片链路测试
├── 失败项目/             渲染失败自动移到这，带 失败原因.txt
├── 项目备份/             --replace 时自动备份的上一版
├── Dify输出/             Dify 原始 TXT / 统一 JSON / HTML / HeyGen 响应
├── HTML预览/             只有 html_document 时的浏览器预览
└── 项目状态.md           在跑 / 待重跑 / 已归档
```

运行时（模板、脚本、GSAP 资产、钉死的 HyperFrames CLI）**不在 `成品/` 里**，在仓库根的
[`runtime/`](../runtime/README.md) —— 它跟成片无关，删了整条链路停工。

## 一个项目目录里有什么

```text
index.html        渲染入口（场景 + 时间线）
render.sh         项目自己的渲染脚本（用 `脚本/` 里的快照）
媒体/             图片、口播、背景音乐、HeyGen 素材
字幕/             最终字幕与时间码
成片/最终视频.mp4  成品；`成片/复核/` 是联系表与响度报告
脚本/             渲染器与检查器的**快照**（改 runtime 不会自动同步到旧项目）
项目说明.md、视频说明.md   由 `runtime/docs/` 复制，**改模板，不改项目里的副本**
诊断/检查结果.txt   检查器输出（只诊断，不阻塞渲染）
```

## 各分类的保留策略

| 目录 | 什么时候来的 | 留多久 |
|---|---|---|
| `<项目名>/` | 统一入口正常出片 | 正式项目，留全套（口播、字幕、图片、成片） |
| `试验/` | 没上线、`-check`/`-rebuild`、结构或图片链路测试 | 结论写进文档后整个删 |
| `失败项目/` | 渲染失败自动移入，带 `失败原因.txt` | 有效输入搬回正式项目重跑后即可删，只留最近 20 个 |
| `项目备份/` | `--replace` 自动备份上一版 | 新版出片正常后即可删，只留最近 20 个 |

## 规矩

- **命名**：正式项目用 `<日期>-<时间>` 或能一眼看出内容的名字；同一个项目的重跑不要再造 `-check` / `-rebuild` 后缀目录，进 `试验/`。
- **保留**：`333`、`Dify输出/333*` 永久保留；正式项目保留全套（口播、字幕、图片）；`失败项目/` 与 `项目备份/` 各留最近 20 个，超出按时间删最旧的。
- **不写回运行时**：任何运行结果不进 `runtime/`；`脚本/` 里的私有配置（`不推送/`）构建时已排除。
- **清理成片时不许连带删 `runtime/`**：它是运行时和模板，不是某一部片子的产物。删了桌面端会弹 `spawn python3 ENOENT`（cwd 没了），整条链路停工；它受 git 跟踪，但 `vendor/node_modules` 不在 git 里，恢复要重装。
- **字幕**只放项目自己的 `字幕/`，不在别处留副本。
- 项目目录**不作为新项目模板**修改——模板在 `runtime/`。
