# 桌面端视觉方向（4 版）

> **已选：02 纸白 Paper**（2026-11-11）。暗色候选是 01 石墨，后续接 `prefers-color-scheme`。

全部是静态 HTML，双击打开即可，不需要服务、不联网。同一份布局与同一套 token 结构，
只换调性——所以选的是方向，不是细节。

## 怎么看

1. 先开 `compare.html`：右下角四个按钮，同一画面实时切换四套主题。
2. 再分别开 `01-graphite.html` / `02-paper.html` / `03-deepspace.html` / `04-film.html` 看单版沉浸感。
3. `tokens.html`：所有 token 的实际取值（颜色、字号、圆角、间距、阴影、字体、动效），同样可切主题。

## 四版差异

| 版本 | 调性 | 强调色 | 圆角 | 适合 |
|---|---|---|---|---|
| 01 石墨 Graphite | 深色中性、紧凑、IDE 感 | 蓝 `#4d7cff` | 6px | 长时间盯着跑工作流、终端和日志 |
| 02 纸白 Paper | 暖白纸面、编辑型 | 墨蓝 `#2d5bd1` | 8px | 大量读/写长提示词，白天、亮环境 |
| 03 深空 Deep Space | 近黑、紫青双色、发光边 | 紫 `#7c5cff` + 青 `#22d3ee` | 10px | 偏“AI 产品”观感，演示、对外 |
| 04 胶片 Film | 暖褐、赭石、衬线标题 | 赭石 `#e0a458` | 4px | 和视频/影视生产的气质一致 |

四版共用：三栏结构（窄工具条 + 画布 + 检视器）、底部运行台/终端/产物、节点状态点、
分支标签、单色终端。也就是说选哪版都不用改布局，只改 `tokens.css` 的主题块。

## 文件

| 文件 | 作用 |
|---|---|
| `tokens.css` | **真正的交付物**：全局 token + 四个主题块。App 以后只 import 这一个文件 |
| `app.css` | 原型布局与组件样式，全部读 token |
| `build.mjs` | 从同一份原型生成 4 个独立版本和 `compare.html` |
| `compare.html` | 四版实时切换 |
| `01–04*.html` | 各方向单版 |
| `tokens.html` | token 速查（带当前主题的实际色值） |

改主题只需改 `tokens.css`，然后 `node build.mjs` 重新生成页面。

## 定下来之后

1. 选一个方向作为默认主题；其余主题块保留还是删掉由你定。
2. 需要“亮/暗跟随系统”的话，把 `paper` 作为亮色、`graphite` 作为暗色，用 `prefers-color-scheme` 挂上去即可。
3. 状态色、终端色、节点色已经拆成独立 token，后面画布组件直接用，不再写死色值。
