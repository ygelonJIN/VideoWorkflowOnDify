# Studio 视觉 v2 · 雾蓝（已落地）

> 唯一主题。`tokens.css` 是 token 源，`renderer/styles/app.css` 消费它。
> 方向：更圆润、内容更大、阴影更足、零图标、更精致。

## 布局

```
┌──────────┬────────────────────────────────┐
│ 左边栏   │ 顶栏（工作流 / 撤销重做在左栏）   │
│ 贯穿整高 ├──────────────────┬─────────────┤
│ 画布     │ 画布 / 产物       │ 节点详情(可收)│
│ 产物     ├──────────────────┴─────────────┤
│ 撤销重做 │ 运行台 / 终端（可收）            │
│ 运行状态 │                                │
└──────────┴────────────────────────────────┘
```

- 顶栏铺到最左，左侧 84px 留给 macOS 红绿灯；左栏与其他卡片一样留 12px 间距，四角 20px 圆角。
- 产物在左栏，占主区三栏（项目 / 文件 / 预览），不再和运行台、终端挤在底栏。
- 右侧详情可收（顶栏「收起详情」），下方控制台可收（标签条「收起」）；收起/展开都不改缩放。
- 顶栏只留工作流选择、加节点、连线、输入、运行、详情开关；撤销/重做放左栏底部；stub 与「跑到哪」收进输入抽屉。

## 交互约定

| 项 | 规则 |
|---|---|
| 滚轮缩放 | `WHEEL_FACTOR = 0.006`：同样滑动距离的缩放幅度是上一版的两倍；下限 = 全图适配 × 0.4（不写死），上限 300% |
| 打开工作流 | 先给 60% 可读比例，以开始节点为中心；「适应」看全图 |
| 点节点 | 只选中 + 更新详情，**不重置缩放** |
| 拖节点 | 只有位置真的变了才写回 YAML，**不重置缩放** |
| 换工作流 | 重新适配一次（按路径判断） |

## 文件

| 文件 | 作用 |
|---|---|
| `tokens.css` | 全局 token（颜色、字号、圆角、阴影、密度） |
| `../renderer/styles/app.css` | 布局与组件，只读 token |

## 零图标

导航、按钮、缩放、节点状态全部文字；连线不带箭头；节点不画端口圆点；
目录行不再用 `▸ / ·` 标记。
