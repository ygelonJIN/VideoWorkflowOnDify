# Studio 视觉 v2 · 雾蓝（已落地）

> 唯一主题。`tokens.css` 是 token 源，`renderer/styles/app.css` 消费它。
> 方向：更圆润、内容更大、阴影更足、零图标、更精致。

## 布局

```
┌──────────────────────────────────────────────┐
│ 顶栏：工作流 · 画布/出片/产物 · 撤销 · 运行 · 设置 │
├────────────────────────────────┬─────────────┤
│ 画布（左上浮动条：加节点/连线/详情）│ 节点详情     │
│                                ├─────────────┤
│                                │ 运行台(可收)  │
└────────────────────────────────┴─────────────┘
```

- 顶栏铺到最左，左侧 84px 留给 macOS 红绿灯；顶栏与其他卡片一样留 12px 间距，四角 20px 圆角。
- **左栏已取消**（2026-11-16）：只有画布 / 出片 / 产物三项，撑不起一列。导航进顶栏中间的分段控件，
  画布因此多出 148px。
- 撤销/重做进顶栏右侧，只在画布视图可用（切到出片/产物变灰）；设置贴顶栏最右。
- 加节点 / 连线 / 详情是画布局部动作，收进画布左上角的浮动条，不占全局顶栏。
- 产物占主区三栏（项目 / 文件 / 预览），和运行台不在同一视图。
- **运行台已从底栏移到画布右栏**（2026-11-21）：画布因此占满左栏全高；出片/产物视图不显示运行台。
- 右侧详情可收（画布浮动条「详情」），运行台可单独收（标题条「收起」）；收起详情时画布连宽度一起让出来，都不改缩放。
- 最小窗口 860×760：视口不够时顶栏自动折成两行，顶栏信息（节点数 / 模型 / key）在 ≤1100 时隐藏；右栏宽度默认 `clamp(340px, 30vw, 404px)`。
- **窗口尺寸按屏幕算**：默认 `min(1480, 工作区宽-40) × min(1180, 工作区高-16)`，关窗记住宽高（不记坐标）。写死 940 在 14 寸上比工作区（1512×885）还高，底边压到程序坞下面；外接屏上又只占一半。
- **面板尺寸能拖、能记**：运行台默认 320（`--bottom-h`），上下拖 `.split-h`；详情栏左右拖 `.split-v`；两者写 `studio.consoleH` / `studio.sideW`。
- **一块可视区只留一条滚动条**：节点详情的代码块 / 输出值、审阅卡口播稿、运行抽屉的批量行都不再自己滚，交给外层。出片日志框只露末尾几行（框里没有滚动条），「展开全部」后由出片页滚。

## 交互约定

| 项 | 规则 |
|---|---|
| 滚轮缩放 | `WHEEL_FACTOR = 0.006`：同样滑动距离的缩放幅度是上一版的两倍；下限 = 全图适配 × 0.4（不写死），上限 300% |
| 打开工作流 | 先给 60% 可读比例，以开始节点为中心；「适应」看全图 |
| 点节点 | 只选中 + 更新详情，**不重置缩放** |
| 拖节点 | 只有位置真的变了才写回 YAML，**不重置缩放** |
| 换工作流 | 重新适配一次（按路径判断） |
