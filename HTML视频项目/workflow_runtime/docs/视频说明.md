# HTML 视频组合说明

本项目不使用视频 Worker。产品 UI、字幕、数据卡片、流程和动效由 HTML/CSS/GSAP 制作。

媒体图层：

- `媒体/HeyGen数字人.mp4`：右上角数字人小窗，`data-video-role="avatar"`。
- `媒体/HeyGen口播.mp3`：主口播，`data-audio-role="voiceover"`。
- `媒体/背景音乐.mp3`：背景音乐，`data-audio-role="background-music"`。

画布固定为 1080×1920、30 秒。内容容器使用全高 flex 布局向画面下方铺满；字幕相对 9:16 根画布固定在中下方 24% 处 `bottom: 24%`，最大宽度 62%，字号 28px，不使用全屏字幕背景。

渲染前 `render.sh` 会执行：

```bash
python3 脚本/sync_video.py --auto-transcribe
```

接近 30 秒的 HeyGen 音视频会统一为 30 秒；其他有效时长按真实较长音轨输出。脚本会让口播、数字人和成片完全一致，并按真实语音时间码写入字幕。


右上角数字人区域是保留区，下面不放置标题、卡片、按钮、产品 UI 或其他文字。
