# HTML 视频组合说明

本项目不使用视频 Worker。产品 UI、字幕、数据卡片、流程和动效由 HTML/CSS/GSAP 制作。

## 媒体图层

完整版：

- `媒体/HeyGen数字人.mp4`：右上角数字人小窗，`data-video-role="avatar"`。
- `媒体/HeyGen口播.mp3`：主口播，`data-audio-role="voiceover"`。
- `媒体/背景音乐.mp3`：背景音乐，`data-audio-role="background-music"`。

无数字人版本：

- `媒体/口播.mp3`：主口播，`data-audio-role="voiceover"`。
- `媒体/背景音乐.mp3`：背景音乐，`data-audio-role="background-music"`。
- 禁止数字人窗口、`data-video-role="avatar"`、数字人媒体占位、黑帧小窗、`.black-frame`、`.avatar-window`、等价空白保留区和删除窗口后残留的右侧避让布局。

画布固定为 1080×1920。字幕固定在中下方 `bottom:15%` 处，水平居中，底板宽度随文字自适应（上限 70%），字号 40px、行高 1.35、字重 700，底板 `rgba(6,10,20,.42)` 半透明，不使用全屏字幕背景；正文可以用满整屏，字幕允许覆盖正文底部。主内容垂直中心以 700–1100px 为舒适区（硬边界 640–1160px），文字、组件之间不得重叠；低透明度装饰层不计入重叠判定。

渲染前 `render.sh` 会识别 `index.html` 的 `data-render-mode`，只给完整版传入数字人视频，并以真实口播为唯一主时钟执行字幕同步、场景/GSAP 校准和生产契约检查；渲染后再检查最终 MP4。口播、场景、字幕、背景音乐及完整版数字人使用同一真实时间轴。

完整版必须保留数字人小窗，位置和尺寸由本次构图决定，且不遮挡标题、卡片、数据、产品 UI 或字幕。无数字人版本不得保留等价窗口、空白区域或布局避让空槽；删除小窗后，顶部标签、标题和相邻组件必须回到正常栅格。
