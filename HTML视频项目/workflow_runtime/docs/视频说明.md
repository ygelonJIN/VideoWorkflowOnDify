# HTML 视频组合说明

本项目不使用视频 Worker。产品 UI、字幕、数据卡片、流程和动效由 HTML/CSS/GSAP 制作。

## 媒体图层

完整版：

- `媒体/HeyGen数字人.mp4`：右上角数字人小窗，`data-video-role="avatar"`。
- `媒体/HeyGen口播.mp3`：主口播，`data-audio-role="voiceover"`。
- `媒体/背景音乐.mp3`：背景音乐，`data-audio-role="background-music"`。

无数字人版本：

- `媒体/口播.mp3`：主口播，`data-audio-role="voiceover"`。
- `媒体/背景音乐.mp3`：背景音乐，`data-audio-role="background-music"`。
- 禁止数字人窗口、`data-video-role="avatar"` 和数字人媒体占位。

画布固定为 1080×1920。内容容器使用全高 flex 布局；字幕固定在中下方 24% 处，最大宽度约 62%，字号固定 37px，不使用全屏字幕背景。

渲染前 `render.sh` 会识别 `index.html` 的 `data-render-mode`，只给完整版传入数字人视频，并执行真实字幕同步、媒体时长校准和生产契约检查。口播、场景、字幕、背景音乐及完整版数字人使用同一真实时间轴。

完整版右上角数字人区域是保留区，下面不放置标题、卡片、按钮、产品 UI 或其他文字。无数字人版本不得保留等价空白区域。
