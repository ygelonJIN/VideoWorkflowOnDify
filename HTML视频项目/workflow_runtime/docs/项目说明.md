# 通用 HTML 视频组合

这是一个 1080×1920、30 秒、25fps 的 HTML/HyperFrames 视频组合，不使用视频 Worker。

## 两种成片模式

- `full`：显示右上角 HeyGen 数字人，使用 `媒体/HeyGen数字人.mp4` 和 `媒体/HeyGen口播.mp3`。
- `black-frame`：不显示数字人，使用 `媒体/口播.mp3`；口播由本地 TTS 或用户提供音频生成。

共同核心文件：

```text
index.html
素材/vendor/gsap.min.js
媒体/背景音乐.mp3
字幕/HeyGen转写.json 或 字幕/口播.srt
```

`index.html` 包含 5 个铺满竖屏的 HTML 场景、真实时间码字幕和确定性 GSAP 时间线。字幕相对 9:16 根画布位于中下方 24% 处，只使用小尺寸文字底板。

最终字幕不由模型估算。`脚本/sync_video.py` 会读取真实 transcript 或本地 ASR 时间码，重写 `CAPTIONS_START` 到 `CAPTIONS_END` 之间的字幕，并按真实口播时长校准场景和成片。

`full` 的右上角数字人区域是保留区，下面不放置标题、卡片、按钮、产品 UI 或其他文字。`black-frame` 禁止保留数字人窗口、avatar 角色或空白数字人占位。
