# 触海科技 HTML 视频组合

这是一个 1080×1920、30 秒、25fps 的 HTML/HyperFrames 视频组合，不使用视频 Worker。

核心文件：

```text
index.html
素材/vendor/gsap.min.js
媒体/HeyGen数字人.mp4
媒体/HeyGen口播.mp3
媒体/背景音乐.mp3
字幕/HeyGen转写.json 或 字幕/口播.srt
```

`index.html` 包含 5 个铺满竖屏的 HTML 场景、右上角 HeyGen 小窗、真实时间码字幕和确定性 GSAP 时间线。字幕相对 9:16 根画布位于中下方 24% 处，只使用小尺寸文字底板。

最终字幕不由模型估算。`脚本/sync_video.py` 会读取 HeyGen transcript 或本地 ASR 时间码，重写 `CAPTIONS_START` 到 `CAPTIONS_END` 之间的字幕，并把口播、数字人视频和成片统一为 30 秒。


右上角数字人区域是保留区，下面不放置标题、卡片、按钮、产品 UI 或其他文字。
