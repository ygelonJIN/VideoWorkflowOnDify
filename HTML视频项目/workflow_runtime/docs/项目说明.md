# 通用 HTML 视频组合

这是一个 1080×1920、25fps 的 HTML/HyperFrames 视频组合，不使用视频 Worker。30 秒只是 Dify 创作阶段的名义长度，最终时长以真实口播为准；场景与字幕使用句子 ID 锚点逐句对齐。

## 两种成片模式

- `full`：显示右上角 HeyGen 数字人，使用 `媒体/HeyGen数字人.mp4` 和 `媒体/HeyGen口播.mp3`。
- `black-frame`（历史模式名）：无数字人、无头像窗口、无黑帧占位，使用 `媒体/口播.mp3`；口播由本地 TTS 或用户提供音频生成。

共同核心文件：

```text
index.html
素材/vendor/gsap.min.js
媒体/背景音乐.mp3
字幕/HeyGen转写.json 或 字幕/口播.srt
```

`index.html` 包含 5 个铺满竖屏的 HTML 场景、真实时间码字幕和确定性 GSAP 时间线。字幕相对 9:16 根画布位于中下方 13% 处，无底板，只显示文字本身。

最终字幕不由模型估算。`脚本/sync_video.py` 会读取真实 transcript 或本地 ASR 时间码，重写 `CAPTIONS_START` 到 `CAPTIONS_END` 之间的字幕，并以真实口播时长为唯一主时钟，通过句子 ID 锚点校准场景、GSAP 相对动效和成片。

`full` 的右上角数字人区域是保留区，下面不放置标题、卡片、按钮、产品 UI 或其他文字。`black-frame` 禁止保留数字人窗口、avatar 角色或空白数字人占位。
