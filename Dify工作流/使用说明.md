# Dify 视频工作流使用说明

黑帧口播（04，默认）三步。命令里**不用写项目名**，自动用时间命名，比如 `20261109-1130`。

## 1 准备

```bash
bash '/Volumes/TUF ESD-T1A Media/视频工作流/HTML视频项目/workflow_runtime/tools/run_dify_output.sh' --prepare
```

打开 TextEdit，粘 Dify 完整输出，保存关闭。生成：

```text
HTML视频项目/20261109-1130/媒体/出图/全部提示词.txt
```

## 2 出图

复制 `全部提示词.txt` 里的提示词去出图，图全部丢进：

```text
HTML视频项目/20261109-1130/媒体/图片/
```

文件名不用改，也不会被改。出片时按修改时间从早到晚对号，**最早那张算 s01**。

## 3 出片

```bash
bash '/Volumes/TUF ESD-T1A Media/视频工作流/HTML视频项目/workflow_runtime/tools/run_dify_output.sh' --skip-images
```

自动用最近一次准备的结果。成片：

```text
HTML视频项目/20261109-1130/成片/最终视频.mp4
```

## 要配的 Key

口播需要 MiMo：

```bash
export MIMO_API_KEY=你的key
```

已有音频就不用：

```bash
bash '/Volumes/TUF ESD-T1A Media/视频工作流/HTML视频项目/workflow_runtime/tools/run_dify_output.sh' --skip-images --voice-file /path/to/口播.mp3
```

## 自动出图（可选）

配好后第 3 步去掉 `--skip-images`，图片自动生成：

```bash
export IMAGE_API_KEY=你的key
export IMAGE_API_BASE=https://api.openai.com/v1
```

火山方舟（即梦同源）：

```bash
export ARK_API_KEY=你的key
export IMAGE_API_BASE=https://ark.cn-beijing.volces.com/api/v3
```

## 想自己命名项目

在命令前加名字，后面步骤跟着用：

```bash
bash '/Volumes/TUF ESD-T1A Media/视频工作流/HTML视频项目/workflow_runtime/tools/run_dify_output.sh' 我的项目 --prepare
bash '/Volumes/TUF ESD-T1A Media/视频工作流/HTML视频项目/workflow_runtime/tools/run_dify_output.sh' 我的项目 "HTML视频项目/Dify输出/我的项目-blackframe-input.json" --skip-images
```

## 出问题

| 症状 | 处理 |
|---|---|
| 「没有 image_plan_json」 | 忘了加 `--prepare`，或 Dify 里还是旧版 YAML |
| 「这些图片没有生成」 | 图没放全。跑 `python3 脚本/ingest_images.py` 看缺哪张 |
| 「缺少 MIMO_API_KEY」 | 配 Key，或加 `--voice-file` |
| 渲染失败 | 项目会移到 `失败项目/`，打开里面的 `失败原因.txt` |
| 想重跑同名项目 | 加 `--replace` |

## Dify 里

导入 `04_黑帧口播_分组生成.yml`。要装 `langgenius/opencode_go:0.5.2` 插件，LLM 节点默认 `gpt-6-luna`。开始节点里选 TTS 供应商和声音，默认 `mimo` + `mimo_default`。
