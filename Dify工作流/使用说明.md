# Dify HTML 视频工作流使用说明

两个 Workflow 的最后一步使用同一条命令：

```bash
bash /Users/jinfeiqing/Desktop/实习/视频工作流/HTML视频项目/workflow_runtime/tools/run_dify_output.sh 你的项目名
```

命令会自动打开 TextEdit。把 Dify 完整输出粘贴到 TextEdit，不要粘贴到终端。内容完整后自动继续，不需要回车、`END` 或读取剪贴板。

## TXT 保存位置

TextEdit 输入文件保存在：

```text
/Users/jinfeiqing/Desktop/实习/视频工作流/HTML视频项目/Dify输出/项目名-年月日-时分秒-dify-output.txt
```

例如本次 `333` 的文件是：

```text
/Users/jinfeiqing/Desktop/实习/视频工作流/HTML视频项目/Dify输出/333-20261023-165412-dify-output.txt
```

每次运行时，终端也会打印本次 `.txt` 的准确路径。

## 自动分流

| Dify 输出 | 自动处理 | 结果 |
|---|---|---|
| `html_document` | 检查 HTML、移除墙钟驱动、统一排版 | HTML 预览 |
| `html_document` + `heygen_response_json` | 下载媒体、同步字幕、渲染 | 最终 MP4 |

项目名建议使用唯一的 `请求编号`，不能包含 `/` 或 `\`。

## Dify 配置

全合一 Workflow 需要：

| 变量 | 说明 |
|---|---|
| `HEYGEN_API_KEY` | HeyGen API Key |
| `HEYGEN_API_BASE` | 默认 `https://api.heygen.com` |
| `HEYGEN_AVATAR_ID` | 数字人 ID |
| `HEYGEN_VOICE_ID` | 中文声音 ID |

模型供应商使用 Qwen / 通义千问 API Key。

## 自动修订与 JSON 容错

### 口播自动修订

`A06_生成口播文案` 的目标是 320–420 个字符、12–18 个完整句子；最终宽门禁为 80–500 个字符、至少 3 个完整句子。

第一次不通过时，Workflow 会携带 `copy_errors_json` 进入 `A06R_按错误自动改写口播`，再由 `A07R_复查自动改写口播` 和 `A07R_口播复查门禁` 复查。仍不通过时输出具体字数、句子数和错误内容。

### JSON 降级处理

- 分镜 JSON 无法解析时，根据口播句子生成基础分镜继续。
- 动效 JSON 无法解析时，生成至少 6 条基础语义动效继续。
- 合规 JSON 无法解析时，按 `needs_changes` 返回可诊断结果。
- 口播 JSON 无法解析时，返回可重试错误并自动改写一次。

降级处理用于避免模型字符串引号、截断或尾逗号直接触发 `json.decoder.JSONDecodeError`，但不能绕过事实、产品和发布前人工复核。

## 布局规则

- 画布始终为 `1080×1920`。
- 主要内容在安全区域内**垂直居中**。
- 水平对齐保持模板原规则：原左对齐仍左对齐，原居中仍居中。
- 内容少时保留自然高度，不强制放大或铺满。
- 顶部品牌、右上数字人、底部状态条和字幕保持固定位置。
- 场景和字幕由 HyperFrames 时间线驱动，禁止墙钟驱动。
- 场景时间禁止二次缩放，BGM 自动补齐到实际成片时长。

## 常见问题

- `402 / Payment Required`：检查 HeyGen Credits、套餐和 API 权限。
- TextEdit 没有保存：在 TextEdit 按 `Cmd-S`。
- 想重新处理：换一个新的项目名。
- 同名全合一项目需要重渲染时：

```bash
bash /Users/jinfeiqing/Desktop/实习/视频工作流/HTML视频项目/workflow_runtime/tools/run_dify_output.sh 项目名 /path/to/dify-output.json --replace
```
