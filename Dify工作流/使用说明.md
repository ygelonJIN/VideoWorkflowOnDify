# Dify 视频工作流使用说明

黑帧口播（04，默认）三步。命令里**不用写项目名**，自动用时间命名，比如 `20261109-1130`。

## 1 准备

```bash
bash '/Volumes/TUF ESD-T1A Media/视频工作流/HTML视频项目/workflow_runtime/tools/run_dify_output.sh' --prepare
```

打开 TextEdit，粘 Dify 完整输出，保存关闭。生成：

```text
HTML视频项目/20261109-1130/媒体/出图/全部提示词.txt
```

## 2 出图

复制 `全部提示词.txt` 里的提示词去出图，图全部丢进：

```text
HTML视频项目/20261109-1130/媒体/图片/
```

文件名不用改，也不会被改。出片时按修改时间从早到晚对号，**最早那张算第一个有图屏**；`role=html` 的屏不占图片位，会被跳过。

图像计划里 `role=html` 的屏不需要出图，它们由 HTML 背景承担画面；出图清单里不会出现这些屏。

## 3 出片

```bash
bash '/Volumes/TUF ESD-T1A Media/视频工作流/HTML视频项目/workflow_runtime/tools/run_dify_output.sh' --skip-images
```

自动用最近一次准备的结果。成片：

```text
HTML视频项目/20261109-1130/成片/最终视频.mp4
```

## 要配的 Key

口播需要 MiMo：

```bash
export MIMO_API_KEY=你的key
```

已有音频就不用：

```bash
bash '/Volumes/TUF ESD-T1A Media/视频工作流/HTML视频项目/workflow_runtime/tools/run_dify_output.sh' --skip-images --voice-file /path/to/口播.mp3
```

## 自动出图（可选）

配好后第 3 步去掉 `--skip-images`，图片自动生成：

```bash

```

## 页面节奏（2026-11-09 起）

- 分镜不再按“一页几句”配额；模型自己决定页数和切点，但每屏的 `voiceover_text` 必须逐字等于这一页实际说到的那段口播原文。
- `H03` 合并时从分镜自动注入 `data-voiceover`，模型不用手写；本地 `sync_video.py` 按这段原文在真实词级时间码里定位页面起点，页长 = 下一屏起点 − 本屏起点。
- 页间转场写绝对秒：builder 第一行 `timeline.__absolutePositions = true`，用 `__sceneStart` / `__cueAbs`；不要把 `__cue()` 的相对秒直接当位置。
- 渲染前新增两道检查：`check_html_timing.mjs`（空页/图片闪回/动作越界，失败会拦）和 `check_motion_variation.mjs`（相邻页动效同签名，只报告）。

## 出问题

| 症状 | 处理 |
|---|---|
| 「没有 image_plan_json」 | 忘了加 `--prepare`，或 Dify 里还是旧版 YAML |
| 「这些图片没有生成」 | 有图屏的图没放全。跑 `python3 脚本/ingest_images.py` 看缺哪张；`role=html` 的屏不需要图 |
| 「缺少 MIMO_API_KEY」 | 配 Key，或加 `--voice-file` |
| 渲染失败 | 项目会移到 `失败项目/`，打开里面的 `失败原因.txt` |
| 本地 ASR 不可用 / 没有时间码 | sync 会重试两次；仍失败时按口播文案估算并写 `字幕/估算说明.txt`，可先出片，修好 ASR 后重跑会精确对齐 |
| 想重跑同名项目 | 加 `--replace` |

## Dify 里

导入 `04_黑帧口播_分组生成.yml`。要装 `langgenius/opencode_go:0.5.2` 插件，LLM 节点默认 `gpt-6-luna`。2026-11-10 起场景页由迭代节点 `H02I` 逐屏调用 `H02S` 生成：导入后确认画布上 `H02I` 里有 `H02S` 一个子节点、`H02J` 接着它，且 `H02S` 提示词里 `{{#h02i.item#}}` 能取到当前迭代项；取不到时退回 `归档/04_黑帧口播_分组生成_分组版备份.yml`。开始节点里选 TTS 供应商和声音，默认 `mimo` + `mimo_default`。
