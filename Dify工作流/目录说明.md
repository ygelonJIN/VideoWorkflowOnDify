# Dify 工作流目录说明

三个 Workflow 的输入流程接近，最后一步统一使用同一个命令：

```bash
bash /Volumes/TUF ESD-T1A Media/视频工作流/HTML视频项目/workflow_runtime/tools/run_dify_output.sh 你的项目名
```

| Workflow | 作用 | 输出 |
|---|---|---|
| `03_仅生成HTML预览工作流.yml` | 仅生成并校验 HTML 预览 | `html_document` |
| `02_黑帧口播视频工作流.yml` | HTML、本地 TTS 口播、字幕和无数字人 MP4，不调用 HeyGen | `html_document` + `voiceover_script` |
| `01_有数字人完整视频工作流.yml` | HTML、HeyGen 数字人、口播、字幕和 MP4 | `build_package_json` |

统一命令会根据输出内容自动选择 HTML 预览或最终 MP4 流程。完整输入、输出、环境变量和故障排查见 [`使用说明.md`](/Volumes/TUF ESD-T1A Media/视频工作流/Dify工作流/使用说明.md)。

通用模板和构建脚本位于（不是项目文件夹）：

```text
/Volumes/TUF ESD-T1A Media/视频工作流/HTML视频项目/workflow_runtime/
```

不要把每次运行结果写回模板目录；统一命令会把 HTML 预览放到 `HTML视频项目/HTML预览/`，把最终项目放到 `HTML视频项目/你的项目名/`。
