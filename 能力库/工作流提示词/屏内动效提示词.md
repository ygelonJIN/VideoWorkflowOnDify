# 单屏动效判断（只做选择，不写代码）

你只判断**这一屏用什么动效**，输出一个 JSON。代码本地按编号展开，**你一个字 JS 都不要写**。

## 输入

- `scene_json`：{{#h02i.item#}}（本屏分镜：`scene_id`、`motion` 节拍、`prev_scene`、`next_scene`、`motion_budget`）
- `scene_html`：{{#h02s.text#}}（本屏标记；`data-anim` 名字从这里抄，逐字一致）

## 输出（只输出 JSON，第一个字符 `{`）

```json
{"scene_id":"s03","motions":[
  {"preset":"T01","target":"title","trigger":"word:答案","fallback":1.2,"params":{"stagger":0.06},"reason":"口播说到答案时文字逐字落下"},
  {"preset":"T06","target":"num","trigger":"sentence_start","fallback":0.3,"params":{"to":128},"reason":"这一屏的核心数字从 0 涨到 128"}
]}
```

- `target`：抄 `scene_html` 里真实存在的 `data-anim` 名（如 `title`、`num`、`media`、`card-1`），只写名字，不要写选择器。
- `trigger`：`word:关键词`（口播里的词）或 `sentence_start`。
- `fallback`：兜底秒数（本屏内相对秒）。**写 0.2–1.2，不要超过 1.5**：写大了动作会拖到这一屏后半段，前几秒是死画面。
- `params`：只覆盖需要改的参数，其余用默认。
- `reason`：一句话，说明对应口播哪一部分。

## 可选编号

| 编号 | 名字 | 适用 | 参数 |
|---|---|---|---|
| T01 | 逐字上浮 | 标题、一句话强调 | stagger |
| T02 | 模糊聚焦 | 副标题、有照片底 | — |
| T03 | 折页落字 | 大标题 | — |
| T04 | 描边写字 | 一个词的重点 | color |
| T05 | 打字机 | 代码、命令行 | — |
| T06 | 数字递增 | 数据、金额、百分比 | from / to |
| T07 | 乱码收敛 | 科技感标题 | seed |
| T08 | 解密揭示 | 代号、版本号 | seed |
| T09 | 翻牌落字 | 短词、价格 | — |
| T10 | 环形文字流 | 片头 2–3 秒 | — |
| T11 | 回声拖影 | 速度感标题 | — |
| X01 | 擦除切换 | 同屏换一版 | — |
| X02 | 淡入替换 | 同位置换文案 | — |
| P01 | 聚光跟随 | 照片块 | — |
| P02 | 边缘受光 | 照片块包边、暗底 | — |
| P03 | 跟随倾斜 | 照片块轻微立体 | — |
| W01 | 照片包裹 | 单张照片是主体 | — |
| U01 | 卡片入场 | 组件卡片 | — |

## 规则

1. 本屏编号已经由全片统一分配：入场用 `scene_json.motion_budget.entrance`，状态变化用 `scene_json.motion_budget.state`。**`preset` 必须原样抄这两个编号，不得更换**（上面示例里的 T01/T06 只是占位）；你只决定 `target`、`trigger`、`fallback`、`params`、`reason`。
2. 每屏**必须输出 2 条**，顺序固定：先入场，再状态变化。两条都不能省。
3. `target` 必须真实存在；名字不清楚就去 `scene_html` 里搜 `data-anim="`。
4. **所有东西都要有入场**：本屏每个 `data-anim` 内容层（除 `bg` / `scrim`）都必须从不可见走到可见，不能停在最终态直接出现；`bg` 和后层底色是唯一的例外，它们在屏起点就在。
5. 入场那条的 `fallback` 就是入场时刻：写 0.2–0.6，最多 1.2。`target` 选本屏的视觉承担者（有照片就用 `media`，无图屏用主文字块或组件），不要选 `bg`。
6. 不要输出代码、注释、解释，只输出 JSON。
