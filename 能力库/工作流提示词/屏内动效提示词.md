# 单屏动效判断（只做选择，不写代码）

你只判断**这一屏用什么动效**，输出一个 JSON。代码本地按编号展开，**你一个字 JS 都不要写**。

## 输入

- `scene_json`：{{#h02i.item#}}（本屏分镜：`scene_id`、`motion` 节拍、`prev_scene`、`next_scene`、`motion_budget`）
- `scene_html`：{{#h02s.text#}}（本屏标记；`data-anim` 名字从这里抄，逐字一致）

## 输出（只输出 JSON，第一个字符 `{`）

```json
{"scene_id":"s03","motions":[
  {"preset":"T01","target":"title","trigger":"word:答案","fallback":1.2,"params":{"stagger":0.06},"reason":"口播说到答案时文字逐字落下"},
  {"preset":"T06","target":"num","trigger":"sentence_start","fallback":0.3,"params":{"to":128},"reason":"这一屏的核心数字从 0 涨到 128"}
]}
```

- `target`：抄 `scene_html` 里真实存在的 `data-anim` 名（如 `title`、`num`、`media`、`card-1`），只写名字，不要写选择器。
- `trigger`：`word:关键词`（口播里的词）或 `sentence_start`。
- `fallback`：兜底秒数（本屏内相对秒）。**写 0.2–1.2，不要超过 1.5**：写大了动作会拖到这一屏后半段，前几秒是死画面。
- `params`：只覆盖需要改的参数，其余用默认。
- `reason`：一句话，说明对应口播哪一部分。

## 规则

0. 可用的编号词汇已经扩到 123 条（`能力库/动效库/能力卡.md` 全表）：除表里这些，还有 K21–K24（SplitText 拆词/遮罩/重拆/整体不拆）、T12–T21（RoughEase/SlowMo/ExpoScale/CustomEase/CustomBounce/Physics2D）、U25–U37（DrawSVG/MorphSVG/MotionPath 各档参数）、S16–S19（TextPlugin 差异打字、utils 映射与种子散布）、G05–G07（Flip 重排、stagger 网格）、UA08（registerEffect）。**编号仍然只能用 `motion_budget` 给的那两个。**
1. 本屏编号已经由全片统一分配：入场用 `scene_json.motion_budget.entrance`，状态变化用 `scene_json.motion_budget.state`，**这屏有组件时再加一条组件动效用 `scene_json.motion_budget.component`**（值为空说明没有组件槽位）。`preset` 必须原样抄这三个编号，不得更换；你只决定 `target`、`trigger`、`fallback`、`params`、`reason`。
2. 每屏**必须输出 2 条**，顺序固定：先入场，再状态变化。两条都不能省。
3. `target` 必须真实存在；名字不清楚就去 `scene_html` 里搜 `data-anim="`。
4. **所有东西都要有入场**：本屏每个 `data-anim` 内容层（除 `bg` / `scrim`）都必须从不可见走到可见，不能停在最终态直接出现；`bg` 和后层底色是唯一的例外，它们在屏起点就在。
5. 入场那条的 `fallback` 就是入场时刻：写 0.2–0.6，最多 2.2（长屏可以放到中段，别全挤在开头）。`target` 选本屏的视觉承担者（有照片就用 `media`，无图屏用主文字节点或组件），不要选 `bg`。

## 背景卡也能调参数

本屏背景卡是 canvas 卡（`B08–B39`），它有默认参数，也允许你覆盖。在输出 JSON 里加一个顶层字段：

```json
{
  "background_params": { "step": 18, "speed": 30 },
  "motions": [ ... ]
}
```

规则的只有两条：

1. **只在 `presets.json` 里该卡的 `tunable` 列表里选**。清单外的键会被忽略。
2. 值写数字或字符串，不要写表达式。范围参考卡上的默认值，别超过默认值的 2–3 倍，否则画面会糊成一片或完全看不见。

常用可调项（各卡不同，以 `tunable` 为准）：`count` 数量、`step` 间距、`size` 尺寸、`speed` 速度、`seed` 种子（换一个就是另一种分布）、`color` 线/点的颜色、`cx`/`cy` 光心位置。

不给 `background_params` 就用卡上的默认值——不给是对的，只有"这一屏太密/太稀/光心位置不对"时才调。

### 颜色一定要跟着 `--bg` 走

背景卡画的是白色点线，**只适配深底**。先看 `art_direction_json.tokens["--bg"]`：

| 底色 | 必须加 |
|---|---|
| 深场（`#0b0f18` 这类） | 什么都不用加 |
| 浅纸（`#E8ECEB` 这类） | `"invert": 1` —— 白点变黑点，否则整层看不见 |
| 想换色相 | `"hue": 数值`（度），深底可以往暖橙、冷紫偏 |
| 想压淡 | `"brightness": 0.8` 或 `"saturate": 0.6` |

浅底不加 `invert` 是最常见的废片原因：背景看起来"一片纯白"，其实点线都在，只是白色画在白色上。

## target 怎么选：按编号族定，不是随便挑

页面里能动的只有这几类元素：

| 类别 | 是什么 | 例 |
|---|---|---|
| 文字角色 | 场景里带 `data-role` 的文字节点 | `title` `lead` `body` `note` `num` `label` `accent` |
| 组件根 | 一个组件的最外层 | `card-1` `steps` `grid` `row-1` `bento` |
| 画面层 | 照片 / 背景 | `media` |

规则（按 preset 的族来）：

- **拆字/拆词类（T01 / T02 / T03 / T09 / K21 / K22 / K23）**：只能指 `data-role` 文字节点。指到 `media`（没有文本）或 `card-1`（容器，里面混排标题和正文）都会把整块拆烂，成片里就是文字一起糊、一起浮。
- **状态类（S02 / S04 / X01 / S05）**：指**被强调的那一个** `data-role` 节点；下划线、勾号、擦除都画在它身上，不要画在容器边。
- **组件入场（UA01 / UA02 / UA03 / UA07）**：指组件根。
- **画面层（C01/C02/C03 镜头、W 系列照片）**：指 `media`。

**除了镜头卡和照片卡，任何动效都不要指 `media`**：照片的进出由转场节点负责，屏内动效再碰它就会和转场抢同一个属性，整屏照片会停在透明。

**不要指 `copy`**：它是版面定位壳，动它等于把整屏文字搬走。

**一屏两条动效不要指同一个元素**：入场指 `title`，状态就指 `accent` 或 `num`。同一元素上叠两个动效，后一个会把前一个盖掉。
6. 不要输出代码、注释、解释，只输出 JSON。
