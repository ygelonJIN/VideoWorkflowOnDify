# 来源台账（谁能进管线、进过什么、删过什么）

改 `presets.json`、或有人拿来一个外部效果问"能不能用"之前读这页。
**判断依据是 `presets.json` 的 `src` 字段**；条目里没有 `src` 的卡就是自有实现，不要再去外部仓库对。

本页一份顶两用：查来历与结论，也查删过什么、还缺什么。

## 一、四条硬标准

一个外部效果能进视频，必须同时满足：

1. 不依赖指针输入（视频里没有鼠标）
2. 不用 WebGL / shader —— **只对 DOM 卡片成立**。照片、遮罩、转场这类画面元素可以用 WebGL：
   `W11–W20` 照片形变走的是 `kit.deform` 的 WebGL1，`--no-browser-gpu` 下走软件 WebGL，
   1080×1920/30fps 与 DOM 卡同量级；gl-transitions 225 支全部编译通过。
3. 能由时间线给 `t` 驱动，任意一帧可 seek
4. 不循环（`yoyo` / `repeat` / 无限跑）

卡在这四条上的，不管多好看都不提。**必须满足 ≠ 自动入目录**：入目录还要看 `role`（见 `经验文档/能力层架构.md`）。

但**先看下面的接口原因**——不先改模型，恢复了也用不上。

原因不是质量，是接口：

- GT 的实现是 `vec4 transition(vec2 uv)` 双图插值，需要 from/to 两张位图 + 一个 shader 画布；
- 现行页间转场是"整页 `[data-scene]` 推上来盖住上一页、上一屏一个元素都不碰"，只动 section 本身，
  没有 from/to 双图，也没有给 shader 的挂载点；
- 两边语义不兼容。硬接的代价是重做转场模型，收益是 68 种观感——**先不付这个代价**。

页间转场现在全部走 `__pt`：`PT01–PT15`（`iris / wipe-diag / curtain / blinds / zoom-cover / push-both /
flip3d / flash-cut / whip / fade-through / squeeze / wipe-up / corner-reveal / slide-down / blur-in`），
由 `H01T` 选编号、`H02T` 调 `window.__pt` 实现。要复活 GT 那一套，先改转场模型（双图缓冲）再谈编号。

## 六、来源怎么标（`src` 唯一字段）

**`src` 必须带来源前缀**，裸机制名（`camera-push` 这种）一律不合法——2026-11-17 之前有 29 张就是这么标的，等于没有来源。

| 前缀 | 含义 | 现存 |
|---|---|---|
| `ui2v:` | `illli-studio/motions` 1,262 包归并；上游一个 Apache-2.0、一个无 LICENSE（见 §八） | 97 |
| `remotion:` | Remotion effects 预设 | 43 |
| `gsap:` | GSAP 官方插件与示例 | 35 |
| `自建:` | 本项目手写，无外部来源。后面跟机制名或批次名（`自建:样张二`） | 29 |
| `components.css` | 组件卡的样式出处是本地组件样式表，不是外部库 | 28 |
| `revideo:` | `revideo-main` 按算法重写 | 27 |
| `motion:` | motion.dev 示例 | 13 |
| `#N 组件名` | reactbits；只有名字和序号，`FoldText`/`SplitFlapText` 在公开目录查不到 | 8 |
| `ported:` | 按算法重写的移植 | 8 |
| `sync_video __pt` | 页间转场的运行时是本地 `__pt`，不是外部库 | 8 |
| `ogl:` | OGL（`oframe/ogl`） | 6 |
| `devicecss:` | `picturepan2/devices.css` v0.2.0（MIT）机身外壳，后面跟机型 | 6 |
| `magicui:` | `magicuidesign/magicui`（MIT）的机制重写，后面跟上游组件名（多来源用 ` + ` 连） | 18 |

**核对方法**（改完 `src` 跑一次，数字对不上就是漏标）：

```bash
python3 - <<'EOF'
import json,re
from collections import Counter
d=json.load(open('能力库/动效库/presets.json'))['presets']
def pre(s):
    m=re.match(r'^([A-Za-z0-9_.\-]+|自建):', s or '')
    return m.group(1) if m else ('reactbits' if (s or '').startswith('#') else s)
print(len(d), Counter(pre(x.get('src')) for x in d).most_common())
EOF
```

**两条没做的**（别当成已完成）：

- `origin` 字段 302 张里 294 张是 null，只有 reactbits 那 8 张填了——**与 `src` 重复，废弃不用**，只认 `src`。
- **`src_url` 还没加**：`src` 只记名字和仓库，不记链接与版本。要长期可追溯、或要对外说明许可（§八），就得补这个字段，动 schema 走 `add_card.py` → `gen_catalog.py` → `check_catalog_sync.py`。

## 九、搬外部素材踩过的坑（都实测过）

1. **CustomBounce / CustomWiggle 缺 CustomEase** → 整段脚本中断，画面静止。
2. **Physics2D 带 `friction`** → 离散积分，seek 停在第 0 步。
3. **Flip 的 `paused:true` 不生效** → 要 `pause(0)` + 主时间线 `progress()` 驱动。
4. **ScrambleText 乱码内容随机** → 同帧两次 seek 不一致，违反确定性。
5. **同名路径上的多个 MotionPath 元素完全重叠** → 做对比必须给不同 duration。
6. **`PathEditor` 只有 ESM** → `<script>` 引不进来，改用 MorphSVG + MotionPath 叠同一段时间。
7. **`source-in` / `copy` 会把整幅照片清掉** → 只在一条横带里演示，带外留原样照片当参照。
8. **示例照片彩度太低** → 滤镜族下面接一条五色色块，合成族把源色换成洋红。
9. **`justifyContent` / `flexWrap` 不能补间** → 改动画数值属性（`width` / `gap` / `flexBasis`）。
10. **落定太快的弹簧读不出来** → 样片慢放 2.4 倍，卡上仍按真实速度。
11. **暗底上黑投影不可见** → 垫一块中灰台面。
12. **`flex:1` 在 auto 高度容器里塌成 0** → 改 `flex:0 0 <px>`。
13. **别为了黑底去改机身配色**（2026-11-17 devices.css 实测）。上游机身是「深色玻璃正面 + 细金属边」，配色是为白底页面定的；落到纯黑舞台上确实不显眼，但把机身刷成浅金属、屏幕刷成浅色界面之后，跟整片暗调主题不符，也不是那台机器本来的样子，已整体回退。要显眼只有两条路：换更亮的背景卡托住机身，或者用 `--dv-z` 放大，**不动配色**。
13. **卡代码有语法错时肉眼只看得到"卡没生效"** → 入表前 `node --check`（见 `经验文档/动效与能力卡.md`）。
14. **CSS `@keyframes` 做的揭示不可 seek**（2026-11-17 rough-notation 实测）→ 上游用 `@keyframes` 推 `stroke-dashoffset` 画线，seek 到中段全部停在终态；改成 timeline 对 `strokeDashoffset` 打 tween 才可复现。凡"用 CSS 动画实现的绘制"都按这条处理，别只换 easing。
15. **`inline-block` 元素只返回一个盒子**（同上）→ `getClientRects()` 拿不到折行，多行标注会整块当一行、线画到下一行去；要用 `Range.selectNodeContents()` 取 line box。

## 附：搬 revideo 时的一条判断

`E` 缓动（31 条）、`LY` 版面（10 条）、`FW` 流程（7 条）**不是卡，是参数**：
缓动是卡内 `ease` 的取值；版面由 `layout_composer.py` 的 `ZONES`/`SCALES` 统一管，卡不写样式；
流程是时序结构（串行/错开/延迟）。这三类只用来判断"哪种重排值得做动效"，不要单独建卡。

不搬的还有：`Rive`（依赖 `.riv` 运行时）、`Video/Audio/Media`（音画同步自己管）、`Latex`（改 HTML 排）、
节点挂 GLSL（已有 `gltrans-kit` 与 three，且契约规定 canvas 与照片默认不同屏）、`Knot/Spline` 拖拽手柄（没有指针输入）、
`cache`/`signals`/`renderer`/`ffmpeg`/`player`/`cli`/`telemetry`（引擎与工程链路，不是画面）。
