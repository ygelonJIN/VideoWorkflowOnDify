# 外部候选评估（怎么判断一个外部效果能不能进我们的管线）

改 `presets.json` 之前读这页。**判断依据是 `presets.json` 的 `src` 字段。** 条目里没有 `src` 的卡就没有外部出处，不要再引外部仓库去对。

## 四条硬标准

一个外部效果能进视频，必须同时满足：

1. 不依赖指针输入（视频里没有鼠标）
2. 不用 WebGL / shader —— **只对 DOM 卡片成立**。照片、遮罩、转场这类画面元素可以用 WebGL：
   `W11–W20` 照片形变从 2026-11-13 起走的就是 `kit.deform` 的 WebGL1，`--no-browser-gpu`
   下走软件 WebGL，1080×1920/30fps 与 DOM 卡同量级。2026-11-14 实测 gl-transitions 225 支全部编译通过。
3. 能由时间线给 `t` 驱动，任意一帧可 seek
4. 不循环（`yoyo` / `repeat` / 无限跑）

卡在这四条上的，不管多好看都不提。

## 五批的来源与结论

| 批次 | 结果 |
|---|---|
| GSAP 插件（15 支） | 只证明"插件能用"。`gsap.min.js` 3.15.1、`vendor/gsap-plugins/` 24 个、`sync_video.py` 注入 12 个视频可用插件 |
| GSAP 进阶（34 支） | 27 入表，7 删（行加词、多段描边、曲线可视化、keyframes、MotionPathHelper、GSDevTools、路径改向） |
| motion.dev（6 支） | 5 入表：`G08` `X30` `X31` `W21` `G09`；M06 删除 |
| motion.dev 进阶（14 支） | 8 留 6 删 |
| Remotion 迁移（32 支） | 21 入表。正式编号查 `src` 里的 `remotion:` 前缀 |
| gl-transitions（225 支 GLSL） | 68 入表（GT01–GT68），6 并入 / 12 淘汰。运行时 `assets/vendor/gltrans-kit.js` |

**没注入的 GSAP 插件**（视频里没意义）：ScrollTrigger / ScrollSmoother / ScrollTo / Observer / Draggable / Inertia / PixiPlugin / EaselPlugin / CSSRulePlugin / GSDevTools / MotionPathHelper / `all.js`。

## 这批踩到的坑

1. **CustomBounce / CustomWiggle 缺 CustomEase** → 整段脚本中断，画面静止。
2. **Physics2D 带 `friction`** → 离散积分，seek 停在第 0 步，画面不动。
3. **Flip 的 `paused:true` 不生效** → 要 `pause(0)` + 主时间线 `progress()` 驱动。
4. **ScrambleText 乱码内容随机** → 同一帧两次 seek 不一致，违反确定性。
5. **`CustomEase.getSVGData` 直接返回 `d` 串**，不是对象；传 `{path:'#curve'}` 它会自己写进元素。
6. **同名路径上的多个 MotionPath 元素会完全重叠**：几张卡走同一条路径做对比，必须给不同 duration，否则看起来只有一张。
7. **`PathEditor` 只有 ESM，dist 里没有 UMD 构建**，`<script>` 引不进来；改用「路径改向 + 跟随」（MorphSVG + MotionPath 叠同一段时间）。
8. **文件名里不能有 `/`**（`动 left/top` 会让 `mv` 失败）。
9. **搬「逃逸」类效果时落点必须明显出界**，否则看不出"逃出裁剪"（motion 批 M03 第一版均差只有 0.4）。

## 来源可信度（`src` 字段三档）

| `src` 形态 | 卡 | 证据强度 |
|---|---|---|
| `remotion:xxx` | 背景 B23–B39、材质 M04/M05 等六大件、离场 X11/X14/X21 | **高**：自带来库名前缀，名字对得上 Remotion effects 预设 |
| `ported:xxx` / `motion:xxx` | G02 G03 I01 I02 S12 W02 Z01 Z02、G08 G09 X30 X31 W21 | **高**：按算法重写，克隆仓库在 `~/Downloads/motion-main 2` |
| `#N 组件名`（reactbits） | T01–T09 X01 | **中**：只写了组件名和序号，没写库名；SplitText/BlurText/TextType/CountUp/AnimatedContent 能对上，`FoldText`、`SplitFlapText` 在公开目录查不到，属疑似 |
| 自有命名（如 `camera-push`） | 其余 | 无外部来源 |

**待办**：`src` 只记名字，没记链接和版本。要长期可追溯得补 `src_url`。

## 三个来源还剩什么值得提

### reactbits（31 文字动画 / 29 Animations / 45 Components / 一批 Backgrounds）

已提 8 个文字动画。**值得再提的只有 4 个**，都是"字"的机制、不依赖指针：

| 组件 | 补什么缺口 | 改造量 |
|---|---|---|
| MaskedHeading | 遮罩揭示（K05 删掉后没有） | 小：clip-path 逐词 |
| TrueFocus | 逐词聚焦（清晰↔模糊序列），K 系列没有 | 小：filter 逐词错峰 |
| DepthText | 分层挤出 + 视差（L01 删掉后没有纵深字） | 中：多层 offset |
| GlitchText | RGB 分离抖动 | 中：`mix-blend-mode` 在这个渲染器出黑块，要换半透明叠加 |

**不建议提**：光标类（BlobCursor/GhostCursor/SwarmCursor 等 20 多个）、shader 类（WarpText/MetallicPaint/FluidGlass）、
物理/拖拽类（FallingText/StickerPeel/Lanyard）、循环 marquee（LogoLoop/TextLoop，我们禁循环）、轮播/画廊类（需要拖拽）。
Components 里勉强可用的 Stepper / Counter，功能已被 S10、T06 覆盖。

### Remotion

已提 22 张，都是 effects 类。剩余：transitions（我们刚把转场裁到 6 张，不需要更多）；
charts 里的**折线图是缺的**（DA 系列只有柱状和行），可以看一眼；3D / audio 类不适合。

### motion.dev

已提 8 张，剩余是手势库、projection 的 112 页断言、WebGPU。
唯一还有价值的是 **scroll 视差**（L01 删掉后没有分层视差）、**shared element 的缩小变体**（G03 只有放大）。

## 许可

- GSAP 3.13 起全插件免费（Webflow 收购后开源），3.15.1 的 `dist/` 可直接 vendor。
- reactbits 是 MIT + Commons Clause：只取机制、不复制代码，别把它的代码原样打进交付物。
- Remotion 本体是 Remotion License（个人与 ≤3 人公司免费商用，禁止拷贝去卖衍生品）；rough-notation/roughjs、gl-transitions 移植件、simplex-noise 都是 MIT。这里的实现是按算法重写的，不是整包 vendor。

## gl-transitions：一次搬一整套，不是搬几个效果

来源 `~/Downloads/gl-transitions-master`（MIT；`InvertedPageCurl` 是 BSD 3 Clause）。目录里 227 个 `.glsl`，
每支都是 `vec4 transition(vec2 uv)` + `progress` 0→1，天然满足"任意一帧可 seek"。跳过 2 支需要宿主
再给一张贴图的（`DisplacementMap` 的 `displacementMap`、`LumaWipe` 的 `luma`），其余 225 支可用。

**为什么这次改了口径**：`不依赖指针 + 不用 WebGL` 这两条原本是给 DOM 卡片定的。照片屏从 `W11–W20`
起一直在用 WebGL1 shader（`kit.deform`），只是当时只搬了一支"形变" shader 的九个模式。这次是把
上游整套转场语言接进来，运行时统一成 `glt.mount(照片元素, 'ShaderName', {from, params})`，
数据文件由 `能力库/动效库/build_gltrans.py` 从上游客商目录生成，不手抄。

**样片分两层**：

- 2026-11-14 的处理：先出 18 张精修候选，再出 225 支全库审阅片；用户从 225 里挑 68 支入表（GT01–GT68），
  精修批 6 支并入 GT、12 支淘汰。**所有候选目录随后清空**（审阅完即删），结果只在
  `样片/全卡审阅/转场/`（68 张确认片）。以后再搬外部素材走 `能力库/动效库/intake.py`：一次渲完，
  选中就地转正、没选中直接删。

筛的报法：报 shader 名或序号；留下的进精修批调参，再走「一批卡入表」那 14 处。

**还没用上的**：225 支里这批只挑了 18 支。剩下的按标签分还有 `wipe`（几十种几何擦除）、`3d`
（Cube / Doors / Sphere / Tunnel）、`light`（LensFlare / LightRays / WarpSpeed）、`retro`
（TvStatic / TvTurnOff / SlotReels）。它们不是不能用，是还没到需要——**不要成批提**，
缺什么补什么，一次 3–4 张，先出样片。

**许可与署名**：数据文件保留每支的作者与 License 注释；上线前不再单独加署名页。
