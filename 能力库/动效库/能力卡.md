# 动效能力卡（给写 GSAP 的节点看）

这一屏能用哪些动作、参数范围多少、什么时候别用。**按编号选，不要自己发明动作参数。**

## 四条硬规则（v2，2026-11-13）

1. **只选表里的编号**，参数只在这个编号给的范围内调；表里没有的动作不要写。
2. **每屏一个主运动**，其余是次级；相邻两屏的主运动不能是同一张卡。切点前 0.3–0.5 秒要有收束（离场或自带回位）。
3. **时间线驱动**：任意一帧可 seek 复现；禁 `requestAnimationFrame` / `performance.now` / `Math.random` / 无限循环。按 `t` 的周期函数（背景、材质、三维）不算循环。
4. **尺寸和坐标由 HTML 给**：`data-flip-to`、`data-morph-to`、`data-frame-to`、`data-pointer-path`。卡不测量布局，唯一例外是指针卡（临时显示隐藏场景量一次）。

## 怎么用

**模型只输出判断，不写代码**（编号的展开代码见 `presets.json`，由 `build_presets.py` / `sync_expander.py` 派生 Dify 模板）：`{"preset":"T01","target":"title","trigger":"word:答案","fallback":1.2,"params":{"stagger":0.06}}`。
本地 `H02SX` 按编号展开成 GSAP 并塞进这一屏。所以：

- 不用记写法，只要选对编号、填对 `target`。
- 代码永远一致，不会因为模型自由发挥而退化。
- 展开模板在 `能力库/工作流代码节点/expand_motion_plan.py`。

## 通用底层能力（任何卡、任何手写场景都能直接调）

`motion-kit.js` 里这 5 个函数不属于某一族，所有卡都能用：

| 函数 | 作用 | 典型用法 |
|---|---|---|
| `kit.fitText({text,withinWidth,fontFamily,fontWeight})` | 反算填满宽度的字号 | 标题自动撑满栏宽 |
| `kit.fitScale(el, ratio)` | 量出要放大几倍才填满父级 | 手写场景里撑满栏宽 |
| `kit.noise2(x,y,seed)` | 确定性 value noise | 有机漂移、手抖、颗粒 |
| `kit.pathAt(el,p)` | 按进度画 SVG 路径 | 折线、连线、手绘线 |
| `kit.drawPath(timeline,sel,at,dur)` | 时间线驱动的路径绘制 | U14 折线、节点连线 |

## 派生与校验

```bash
python3 能力库/动效库/sync_expander.py                 # 把 ready 卡同步进 Dify 的 H02SX
python3 能力库/动效库/sync_expander.py --check         # 只在 CI/交付前检查是否同步
```

**加卡的完整流程**（三步，缺一步就等于没加）：

1. 改 `presets.json`（唯一源）
2. 跑 `sync_expander.py`——展开器里的 `TPL` / `DEFAULTS` 是生成的，不再手抄
3. 出样片：`make_review_reels.py` 重出工程 → 渲染（见 `样片/README.md`）

现状：**67 条编号，全部可用**，展开器已同步 54 条（背景 13 条走 bgkit，不进 TPL）。

## 交互（I 系列，2026-11 新增）

指针不是真鼠标，是页面上一个 `.ptr` 元素；卡只负责把它挪过去、切手型、点一下。
**HTML 契约**：放一个 `<svg class="ptr">`（内联箭头，热点在左上角），再给要点的元素起个 `data-anim`。卡自己量目标元素的中心，**不用写坐标**（2026-11-13 改：以前写死坐标，版面一改就点空）。

| 编号 | 名字 | 参数 | 什么时候用 | 别用在哪 |
|---|---|---|---|---|
| I01 | 指针点击 | 移动 0.8s · 悬停 0.3s · 回弹 0.42s | 单次点击：点选、确认、展开 | 一屏点三次以上；指针压住正文 |
| I02 | 指针多步 | `data-pointer-path` 列目标名 · 每步 0.55s + 点击回弹 | 多步操作：选行 → 填表 → 提交 | 目标元素不存在；超过四步 |
