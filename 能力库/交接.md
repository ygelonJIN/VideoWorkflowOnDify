## 加一张卡（四步）

1. **先出样片**：直接写一版 1080×1920 的场景，或先在 `presets.json` 里写卡再 `render_card.sh` 出片；没样片不入表。
2. 改 `presets.json`：`id name family layer status cap params use avoid code`，`code` 里用 `{{sel}}` `{{at}}` `{{参数}}`。
3. 同步链，**顺序不能反**：
   ```bash
   cd 成品/workflow_runtime/tools && python3 sync_prompts_to_yaml.py     # 提示词镜像 → YAML
   cd - && python3 能力库/动效库/sync_expander.py                        # TPL/DEFAULTS → YAML
   python3 能力库/动效库/sync_expander.py --check                        # 必须通过
   ```
4. 出这一张的样片：`bash 能力库/动效库/render_card.sh <编号>`（约 7 秒）。

## 删一张卡

改 `presets.json` + `能力卡.md` → 跑上面同步链 → 删掉该卡的样片和 `源/<族>/<编号>/`。

## 渲染（任何样片）

```bash
HYPERFRAMES_BROWSER_PATH="/Applications/Google Chrome.app/Contents/MacOS/Google Chrome" \
  ~/.nvm/versions/node/v22.23.3/bin/node \
  "成品/workflow_runtime/vendor/node_modules/hyperframes/bin/hyperframes.mjs" \
  render . -w 1 -f 30 -q looks --no-browser-gpu --experimental-fast-capture=false -o out.mp4
```

- `--experimental-fast-capture=false` **不能省**，否则纯 DOM 合成会走 `drawElement` 捕获直接失败。
- 超过 ~20 秒的合成容易踩这个坑以外的性能问题，长片拆段再 `ffmpeg concat`。

## 三条硬规矩

1. **样片门槛**：新卡先出片给用户看，点头才写入 `presets.json`。
2. **尺寸和位置由 HTML 给，卡不猜**：`data-flip-from/to`（G02）、`data-morph-to`（G03）、`data-frame-to`（W02）、`data-pointer-path`（I02）。卡只做插值，不测量布局（几何测量只在指针类卡里，且要临时显示隐藏场景）。
3. **字永远在 canvas 之上**：三维/背景卡只负责画面，文字留在 HTML 层。
