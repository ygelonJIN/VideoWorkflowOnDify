# 画面工艺参考

这里存放制作层面的工艺参考：构图、动效、声音和节奏怎么做到位。**不进入提示词，也不约束模型的创作方向**——模型仍然自己决定风格、版式和动效。这些文档是给人和后续调优看的参考，遇到具体问题时查对应那一篇。

## 什么时候读哪篇

| 文件 | 什么时候读 |
|---|---|
| `讲解类图形.md` | 要把一个道理、流程、结构或数据讲清楚时 |
| `动效图形与推广片.md` | 做动态字、界面演示、产品介绍、片头时 |
| `风格化外观.md` | 指定了某种风格、材质或流派（水墨、像素、剪纸、复古等）时 |
| `模拟与生成.md` | 粒子、群集、元胞自动机、物理、场、着色器等生成式画面 |
| `角色与生物运动.md` | 画面里有人、动物或角色在动 |
| `三维场景与镜头.md` | 三维场景、产品展示、运镜 |
| `声音设计与旁白.md` | 任何带声音的片子：旁白、音乐、音效、环境声 |
| `音乐与卡点.md` | 音乐主导的片子、按节拍切画、给定曲目或歌词 |

## 和本仓库脚本的对应关系

文档里提到的脚本，在本仓库的位置如下（项目内的 `脚本/` 目录是运行时副本）：

| 文档里的名字 | 本仓库位置 | 用途 |
|---|---|---|
| `audio_check.sh` | `成品/workflow_runtime/scripts/audio_check.sh` | 响度、真峰、削波、长静音、音视频时长一致性 |
| `audio_sync_check.py` | `成品/workflow_runtime/scripts/audio_sync_check.py` | 事件时间与音轨起音点对齐（毫秒偏差） |
| `sound_kit.py` | `成品/workflow_runtime/scripts/sound_kit.py` | 程序化音效/配乐素材（纯 numpy，确定性） |
| `contact_sheet.sh` | `成品/workflow_runtime/scripts/contact_sheet.sh` | 成片联系表，一次看完所有镜头 |

`capture_seek.mjs`（同目录）是按 `window.seek(t)` 逐帧抓取的备用渲染路径，只有页面自己暴露 `seek(t)` 时才用得上；本仓库主线走 HyperFrames，一般不需要。

## 使用边界

- 这些文档描述的是"把影片当成时间的函数来画"的思路；本仓库主线是 HTML/CSS + GSAP 时间线，思路相通但接口不同，照抄代码前先看 `经验文档/使用说明.md`。
- 涉及阵列、节奏和音画同步的建议可以直接用在提示词调优和人工复核上。
