# 能力库索引

`能力库/` 只放以后还会反复使用的长期资料：定义、生产标准。
**提示词与 Code 节点的唯一源是 `Dify工作流/*.yml`**，这里不留副本。

## 这里有什么

| 位置 | 内容 |
|---|---|
| `动效库/presets.json` | 卡的唯一源：编号、名字、族、`role`、参数、代码、来源 |
| `动效库/能力卡.md`、`组件卡.md` | 生成物（`gen_catalog.py`），别手改 |
| `动效库/来源台账.md` | 来源、结论、删过的编号、当前缺口、许可 |
| `动效库/样片/全卡审阅/` | 每张卡一张 3 秒确认片 |
| `项目文档/` | 任意主题通用的标准：`用户输入事实与合规规则.md`（含选题与去重）、`视频需求与质量标准.md` |

目录职责与脚本清单只有一份，在根目录 `AGENTS.md`。

## 输入提炼层（所有 Workflow 共用）

`S1` 先从 `brief` 提炼出 `distill`（主张 + 论点 + 证据），把任意形态的输入（聊天记录、会议纪要、文章、语音转写、清单、碎片想法）
先压成"一个主张 + 支撑它的论点 + 证据"，条数不设配额：

| 字段 | 含义 |
|---|---|
| `source_form` | 输入形态，用于判断是不是素材 |
| `thesis` / `thesis_source` / `thesis_type` | 一句话主张、来源、类型 |
| `arguments[]` | 条数由素材决定；每条含 `claim` / `evidence` / `support` / `strength` |
| `counterpoints` | 需要正面回应的相反说法 |
| `dropped` | 被丢弃的类别（寒暄、重复、跑题等） |
| `open_questions` | 素材没讲清、成稿不得编造的点 |

`S1` 一次写出「口播 + 分镜」，`S1N` 把分镜对齐原文并打包，`S1_门禁` 拦流水账/照搬/漏论点——全部以 `distill` 为脊柱。
这些提示词只在 `Dify工作流/04_黑帧口播_分组生成.yml` 里，**不在能力库留镜像**。

## 改卡的正确入口

```bash
python3 能力库/动效库/add_card.py 新卡.json      # 加
python3 能力库/动效库/remove_card.py T27          # 删
python3 能力库/动效库/gen_catalog.py              # 只重生成两份表与 H00 目录
python3 能力库/动效库/check_catalog_sync.py       # 四层一致性门禁
```
